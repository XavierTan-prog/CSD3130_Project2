# Seam Carving: DP vs Greedy vs Graph Cut

CSD3130 Assignment 2. Content-aware image resizing with the seam-finding
step implemented three ways: dynamic programming, greedy, and graph cut
(min-cut / max-flow).

## Build (Windows, Visual Studio 2022 + vcpkg)

One-time vcpkg setup:

```powershell
git clone https://github.com/microsoft/vcpkg C:\dev\vcpkg
C:\dev\vcpkg\bootstrap-vcpkg.bat
```

Then double-click `run.bat`. It takes no arguments: it generates the Visual
Studio solution in `build\` (finding Visual Studio's CMake by itself) and
opens it. If vcpkg is not at `C:\dev\vcpkg`, set `VCPKG_ROOT` first.

Two more scripts, also argument-free:

| Script | What it does |
| --- | --- |
| `clean.bat` | Deletes `build\` and the `bench_*.png` outputs. Close Visual Studio first. |
| `rebuild.bat` | Runs `clean.bat` then `run.bat`: regenerates the solution from scratch and opens it. |

Everything else is launched from Visual Studio. Right-click a project >
**Set as Startup Project**, then press **Ctrl+F5** (run) or **F5** (debug):

| Project | What it does | Default arguments |
| --- | --- | --- |
| `seam_carve` (default) | Resizes an image | `images/input/sample.png images/output/sample_dp.png 150 120 dp` |
| `benchmark` | Times the three methods | `images/input/sample.png 10` |
| `tests` | Runs the unit tests | none |

To use another image, size or method, change `VS_DEBUGGER_COMMAND_ARGUMENTS`
in `CMakeLists.txt` and build once, or override it for yourself under
Project > Properties > Debugging > Command Arguments.

The solution is generated by CMake: to add or remove source files, edit
`CMakeLists.txt` rather than the solution, then build again.

The same steps by hand (the first configure builds OpenCV and is slow):

```powershell
cmake -B build -S . -DCMAKE_TOOLCHAIN_FILE=C:/dev/vcpkg/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

## Run from a terminal (optional)

```powershell
# seam_carve <input> <output> <width> <height> [dp|greedy|graphcut]
build\Release\seam_carve.exe images\input\sample.png images\output\sample_dp.png 150 120 dp

# benchmark <input> <seams-to-remove>
build\Release\benchmark.exe images\input\sample.png 10
```

## Layout

| Path | Purpose |
| --- | --- |
| `include/seam_carving/`, `src/` | Library: energy map, three seam finders, seam removal |
| `src/main.cpp` | Command-line resizer |
| `bench/benchmark.cpp` | Running-time comparison |
| `tests/` | Catch2 unit tests |
| `images/input/`, `images/output/` | Test images and generated results |
| `report/` | Report material and AI usage log |
